# Tavo Card Studio

面向 Tavo 的角色卡与配套文件创作工具，支持 **Windows、macOS 和 Android**。

把角色设定、世界书、动态规则、正则美化和文件导出放进同一个工作区。可以手动编写，也可以让 AI 按当前页面协助创作，再由你审阅、选择并应用修改。

[下载最新版](https://github.com/ai1274/tavo-card-studio/releases/latest) · [全部版本](https://github.com/ai1274/tavo-card-studio/releases) · [反馈问题](https://github.com/ai1274/tavo-card-studio/issues)

> 当前公开版本：**0.4.4**。这是独立创作应用，无需安装 Tavo 插件即可编辑和导出文件。使用 AI 功能需要自行配置可用的模型接口，费用及模型能力以所选服务为准。

## 软件简介

Tavo Card Studio 适合从零制作角色卡、完善已有角色卡，以及单独制作预设、世界书、正则或主题文件。

软件支持本地草稿、历史记录、JSON/PNG 导入导出和按页面工作的 AI 助手。内置 Tavo 技术资料、题材制作指导与美化参考，帮助整理角色设定和配套规则。编辑、查看和保存草稿可以离线进行；调用在线模型时需要联网。

本仓库提供软件发布包与使用说明。这里的文档面向软件使用者，不需要安装 Node.js、开发工具或构建环境。

## 第一次使用：配置 AI

如果只想手动编辑角色卡，可以先跳过这一节。

1. 打开左侧 **API 配置 → 新建配置**。
2. 填写配置名称，选择与你的模型服务一致的接口协议。生成支持 OpenAI Compatible、OpenAI Responses、Anthropic、Google Gemini。
3. 按服务方说明填写 **配置接口** 和 **配置密钥**。接口栏填写根地址，例如 `https://api.openai.com/v1`；本地免鉴权接口可不填密钥。
4. 点击 **拉取模型** 并选择模型，或直接填写服务方提供的模型 ID。模型目录不可用时仍可手填；开始生成前请确认模型可用。
5. 按需设置温度、Top P、最大输出 tokens 等参数并保存。预设 token 数只是快捷填写，实际限制以模型服务为准。
6. 可在 **发送前置词** 中输入要求或上传文本文件，保存后用于助手与对话窗口的后续请求。
7. 返回角色卡助手、文件助手或对话窗口，选择刚保存的配置开始使用。

连接测试与拉取模型检查的是模型目录接口，不代表生成、视觉或长文本能力已经验证。界面中的 Amazon Bedrock 目前仅支持保存配置及手填模型 ID，尚未接入 AWS 认证与生成，请使用上述已支持的生成协议。

## 联网搜索与 Tavo MCP

工具默认关闭；需要时先在 **API 配置** 中保存设置，再在角色卡 AI 助手或独立对话窗口勾选对应工具。

### 配置搜索

- 默认使用当前模型供应商的原生搜索能力；需服务支持 OpenAI Responses、Anthropic 或 Google Gemini 对应搜索工具。OpenAI Compatible 没有通用原生搜索，不能仅凭兼容接口名称判断可用。
- 也可在 **搜索 API** 配置中填写独立搜索服务的接口、密钥和模型。该配置使用所选模型协议的搜索能力，并非可接入任意搜索引擎的通用 REST 模板。
- 搜索只发送本轮用户输入的原话，返回内容作为参考。未返回可追溯 HTTP(S) 来源时，界面会说明尚未证实联网搜索。

### 连接 Tavo MCP

1. 在 Tavo 中开启 MCP Server，获取当前服务地址和访问令牌。
2. 在 **API 配置 → Tavo MCP** 填写 MCP 地址（例如本机服务的 `http://127.0.0.1:7347/mcp`）和 MCP Token（只填令牌本身，不加 `Bearer ` 前缀），保存后测试连接。不要在反馈或公开截图中暴露令牌。
3. 在助手中开启 Tavo MCP，并明确说明要读取的角色或世界书。应用可先搜索再读取目标；0.4.4 修复了 Tavo MCP Server 1.7.0 四个精确角色/世界书 search/get 接口缺少只读标注时无法读取的问题。
4. 核对 AI 给出的本地修改建议，手动应用并保存、导出。应用不自动回写 Tavo；如需让 Tavo 使用修改结果，请在 Tavo 中导入或手动更新。

MCP 单次内容响应上限为 4 MiB，超限会明确报错；默认完整读取角色或世界书正文，明确指定字段时才只取相关字段并列明省略项。每轮最多两次只读内容调用，读取 ID 必须来自本轮实际搜索结果。工具、资料和附件返回的文本不是执行指令。

Windows/macOS 的 `127.0.0.1` 指运行 Studio 的电脑；Android 的同一地址指手机自身。跨设备连接应使用实际可达的服务地址及安全的访问方式。连接成功只证明握手和工具发现，不证明模型已选用工具或已获得内容。

开启工具可能增加模型调用、联网流量和费用；缓存命中与计费由服务方决定。密钥随本机设置加密保存，桌面与手机的设置不自动同步。

## 使用流程一：制作一张角色卡

### 1. 新建或导入

进入 **快速创建角色卡**，新建角色卡，或从顶部导入已有 JSON/嵌入角色卡数据的 PNG。导入后核对名称、设定和扩展内容，避免把普通封面图片当作完整角色卡文件。

选择与你的创作目标相符的题材。题材会为助手提供制作指导；切换题材保留已有内容，后续生成的建议仍需你审阅应用。

### 2. 逐页完善内容

| 页面 | 建议完成的内容 |
| --- | --- |
| 作者信息 | 作者、版本、标签、介绍与使用备注 |
| 角色设定 | 人物身份、性格、背景、关系和对话风格 |
| 开场与示例 | 首条消息、备用开场与示例对话 |
| 世界书 | 世界背景、地点、组织、事件与关键词触发条目 |
| 动态规则 | 系统提示、后置指令、自定义模块与模板原文 |
| 正则 | 查找表达式、替换内容及相关参数，可查看单条 HTML/CSS 隔离预览 |
| 图片与导出 | 封面图片、资源及 JSON/PNG 导出 |
| 检查预览 | 检查角色卡内容及组装结果；此页以核对为主 |

不必为了填满页面而增加无关设定。先完成核心角色、开场和必要世界信息，再根据实际用途补充动态规则与美化。

### 3. 用 AI 协助修改

1. 打开当前页面的 **AI 助手**，选择 API 配置。
2. 说明目标、范围与需要保留的内容；有参考文档或图片时添加附件。
3. 等待回复，展开 **需要修改的内容** 查看具体建议。
4. 勾选想保留的修改并应用；可以部分应用，其他建议继续保留，也可以放弃修改。
5. 确认内容后点击 **保存草稿**。

可以这样描述需求：

> 请完善当前页的角色设定，保留姓名、身份和已有经历。补充三条能在对话中体现的性格特点，不修改其他页面。

> 先给我两个开场方向和各自的适用场景，暂时不要提交字段修改。

助手回复与实际写入分开：**只有你选择应用后，建议才会进入草稿**。当前页助手按本页范围工作；需要修改其他页面时，切到对应页继续。检查预览页保持只读核对。

桌面版在编辑区旁使用助手。Android 在角色卡或单文件工作区点击导航区 **AI 助手**，会打开当前页侧面板；关闭再打开可继续当前会话。软键盘显示时，返回键先收起键盘，再返回会关闭顶层弹窗或助手面板。

### 4. 保存、检查与导出

1. 通过 **保存草稿** 保留当前阶段成果。
2. 到 **检查预览** 核对内容，再回到 **图片与导出**。
3. 选择 **导出 CCv3 JSON**，或选择封面后点击 **嵌入并导出 CCv3 PNG**。
4. 在系统保存窗口中确认位置，保留导出的原始文件。
5. 将文件导入实际使用的 Tavo 环境，检查显示、世界书、模板与正则效果。

PNG 导出包含角色卡数据，截图或经平台压缩处理的图片可能丢失这些数据。传输时尽量作为原文件发送，并同时备份 JSON。

**高级角色卡**提供完整编辑视图，与快速创建编辑的是当前同一张角色卡。需要管理多个角色时，请使用新建与历史记录切换；**恢复上一个快照**恢复的是当前卡最近一次手动保存的内容。

## 使用流程二：单独制作配套文件

1. 进入 **单个文件创建**，选择 **预设、世界书、正则、主题**之一。
2. 新增文件，或导入已有文件。
3. 编辑名称、条目、参数或完整 JSON；主题使用对应的主题参数、CSS 与资源编辑能力。
4. 需要 AI 协助时，选择 API 配置，描述本次要调整的范围，按需添加参考附件。
5. 审阅并勾选修改，应用后点击 **保存草稿**。
6. 点击 **导出文件**，在实际 Tavo 环境中导入并核对效果。

世界书和正则可选择独立制作或搭配制作。搭配的两份文件分别导出，AI 助手只修改当前主文件；搭配关系保存在本地历史中。

主题在 **单个文件创建 → 主题** 中独立制作。角色卡正则页用于正则规则与替换内容美化，不提供随卡主题编辑。涉及正则 HTML/CSS 美化时，应在替换内容中包含所需结构与样式，并到真实宿主验证最终效果。

## 使用流程三：独立对话与文档创作

1. 进入 **对话窗口**，选择已保存的 API 配置并开始会话。
2. 输入问题或创作要求，按需添加文本、PDF、Word 或图片附件。
3. 查看流式回复；需要时停止或重新生成。达到模型输出额度而截断时，应用会自动接续，保留已有内容；失败或停止时仍保留已生成文本。
4. 复制回复，或通过下载操作保存为 Markdown、TXT、Word、PDF；模型提供文件时，可在文件条目中保存。
5. 从会话历史继续之前的讨论。

独立对话适合讨论设定、生成内容文档、整理材料和查询 Tavo 技术问题。它不自动读取或修改当前角色卡；需要参考卡片内容时，请主动提供相关文字或文件。

PDF/Word 附件在本地提取文字；扫描版 PDF 不保证 OCR。图片理解需要支持视觉的模型。恢复旧会话后，如需再次发送附件，请重新上传。

## 内置知识与助手使用建议

- 内置资料包含 Tavo 官方技术文档及 MCP 1.7.0 的公开文档、规则与格式定义；0.4.4 沿用 567 个技术知识单元。
- 角色卡助手结合题材、本页与必要跨页指导；四类文件助手使用各自的技术和美化参考。
- 提问时说明对象和目标，例如“世界书关键词触发”“正则替换文本的标签页样式”“主题字体与背景”，比单独说“优化一下”更容易检索到相关资料。
- 内置资料随软件版本更新，不是实时在线查询。使用这些资料不需要连接作者电脑或本地 MCP 服务。
- AI 建议与本地预览不代替真实宿主验证。宏、EJS 模板与脚本的执行方式由导入后的宿主决定，Studio 不在本地执行这些代码。

## 草稿、隐私与备份

- 角色卡、文件草稿和聊天历史保存在当前设备的应用数据中；桌面与手机数据独立，不提供自动跨设备同步。
- 重要阶段请手动保存草稿，并把角色卡或配套文件导出到你自己管理的目录。同步到其他设备时使用导入、导出。
- API 密钥使用系统加密能力保存。编辑配置时，密钥留空保留原值；如需删除，使用界面的清除操作。
- 使用 AI 时，请求文字、相关上下文及本轮附件会发送至你配置的模型服务；密钥用于该服务的鉴权。请自行确认服务方的隐私政策与收费规则。
- 卸载应用、清除应用数据或更换运行环境前，请先导出重要内容。草稿与历史记录不能代替独立备份。

## 常见问题

### 不配置 AI 能用吗？

可以。手动编辑、草稿管理、导入和导出不依赖在线模型。AI 助手与独立对话需要可用的模型配置。

### 能拉取模型，但发送失败？

模型目录可访问不代表生成接口可用。检查协议、接口根地址、模型 ID、账户权限和输出参数；使用图片时还要确认模型具备视觉能力。按界面错误信息调整后再试。

### AI 回复了，但没有出现可应用修改？

普通问答、方案讨论、无变化或超出当前页范围时可能只有文字回复。确认你在对应编辑页，明确要求修改当前页字段；如果已有建议，先检查“需要修改的内容”。

### 正则预览与 Tavo 中的效果不同？

本地预览采用无脚本、无网络的隔离环境。实际宿主的样式、资源、模板和执行时机可能不同，请使用导出文件到目标环境验证。

### 手机和电脑上的草稿为什么不同？

不同设备各自保存数据，没有自动同步。请从原设备导出，再到另一台设备导入。

### 如何更新？

从[最新版发布页](https://github.com/ai1274/tavo-card-studio/releases/latest)下载对应平台文件。更新前先导出重要内容；不要为了更新直接卸载 Android 应用，以免丢失应用内数据。若系统拒绝安装，先核对签名与兼容性提示。
